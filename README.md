# 邊坡演育互動模擬器

地形學課程作業的輔助工具。透過調整初始坡形與模型參數，觀察邊坡在 500、1000、2000、5000 年後的剖面變化，並查看有限差分公式的數值代入與物理意義。

## 開啟方式

- 線上：本專案啟用 GitHub Pages 後，由儲存庫的 Settings → Pages → Visit site 開啟。
- 本機：下載 `index.html`，用 Chrome、Edge 或 Firefox 開啟。
- 需連線載入 D3 與網頁樣式所用的外部資源；不需要登入 ChatGPT，也不需要安裝程式。

## 功能與操作

1. 選擇階梯陡坎、折線坡、三角山丘、起伏斜坡或直線坡。
2. 調整 K、Δx、Δt、剖面長度、高差、基準高程、轉折位置及過渡寬度。
3. 選擇固定高程或封閉邊界，觀察各年份剖面；點選圖例可隱藏或顯示曲線。
4. 點選剖面位置，或移動位置滑桿，查看左右鄰點如何算出下一步高程。
5. 比較課程 Excel 與講義參數。這兩個按鈕只切換 K、Δx、Δt，不會重設坡形。

## 模型原理

一維線性擴散方程：

```text
∂z/∂t = K · ∂²z/∂x²
qₛ = −K · ∂z/∂x
```

| 符號 | 意義 | 單位 |
| --- | --- | --- |
| z | 地表高程 | m |
| x | 水平位置 | m |
| t | 時間 | 年 |
| K | 地貌擴散係數 | m²/年 |
| qₛ | 每單位剖面寬度的體積輸砂通量 | m²/年 |

顯式有限差分更新：

```text
r = K · Δt / Δx²
z新 = z中 + r · (z左 − 2z中 + z右)
```

模型要求 `r ≤ 0.5`；超出時會停止計算並顯示提示。指定年份不足完整一步的部分，採縮短最後一步的方式計算。

凸起處曲率為負，高程降低；凹處曲率為正，高程升高。直線坡段即使有泥沙通過，流入與流出平衡時，高程也可能暫時不變。因此，坡度很陡不代表當地高程一定快速降低。

## 作業比較設計

研究問題：初始邊坡的陡緩與轉折形狀，如何影響後續演育？

共同條件：長度 100 m、高差 5 m、基準高程 40 m、K = 0.1 m²/年、Δx = 5 m、Δt = 100 年，兩端固定。比較 0、500、1000、2000、5000 年。

| 組別 | 坡形 | 轉折位置 | 過渡寬度 |
| --- | --- | --- | --- |
| A | 階梯陡坎 | 52.5% | 不適用 |
| B | 平台—斜坡—平台 | 50% | 20% |
| C | 平台—斜坡—平台 | 50% | 60% |

A 組在 5 m 網格上，以 x = 50 m 為高平台最後一點、x = 55 m 為低平台第一點；它的離散轉折中心與 B、C 組略有差異，解讀局部差異時應注意。

建議每組畫一張包含五個年份的比較圖，並採相同座標範圍。若截取本工具畫面，應一併保留參數；正式跨組製圖時需核對座標範圍，因本工具會自動縮放縱軸。

### 討論方向

- 哪些位置先出現明顯降低或墊高？是否集中在轉角附近？
- 凸形與凹形位置的變化，是否符合曲率與侵蝕、堆積的關係？
- 直線坡段是否暫時維持原狀？如何用泥沙收支解釋？
- 5000 年後，還保留多少初始坡形差異？
- 固定同一坡形，比較 K = 0.02 與 0.1，可觀察搬運效率對演育速度的影響。

以上為實驗設計與待檢驗問題，並非已完成的模擬結果或觀測結論。報告應依實際操作結果撰寫。

## 邊界條件與限制

- 固定高程：兩端維持初始值，允許與外部交換泥沙，因此剖面內面積不一定守恆，也不一定演化為水平面。
- 封閉邊界：以鏡射鄰點施加零坡度；兩端不輸砂，梯形積分的剖面面積在數值精度範圍內守恆。
- Δx 與 Δt 是數值離散參數，會影響解析度與近似誤差。
- 本工具假設 K 均一且不隨時間改變，未包含河流下切、地殼抬升、土壤生成與突發崩塌。
- 陡坎為理想化教學條件；陡坡輸砂可能呈非線性，不能將此工具直接用於真實邊坡災害預測。
